# GameDesk — سريع + Supabase (متعدد الأجهزة)

## الفكرة
- التطبيق **يفتح فوراً** من كاش الجهاز (مفيش انتظار "جاري الاتصال").
- المزامنة مع Supabase تحصل **في الخلفية**.
- أي جهاز يفتح الموقع يشوف نفس البيانات ويتحدث لحظياً (Realtime).

## أول مرة فقط
1. افتح مشروع Marseille Academy على Supabase
2. SQL Editor → New query
3. الصق ملف `gamedesk-supabase-setup.sql` واضغط Run

## الاستخدام من أكثر من جهاز
ارفع المجلد على أي استضافة HTTPS وافتح نفس الرابط من الموبايل/الكمبيوتر/التابلت.

## الحالة اللي هتشوفها
- `محلي • جاري المزامنة...` لحظة الفتح
- `متصل • متزامن بين الأجهزة` بعد نجاح المزامنة
- `محلي • تعذر المزامنة` لو النت ضعيف — التطبيق يفضل شغال عادي

## التنبيهات
- رنة + إشعار متصفح
- واتساب برسالة جاهزة (سجّل الرقم من الإعدادات)
- لازم الصفحة تكون مفتوحة والتنبيهات مفعّلة مرة واحدة
