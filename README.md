# GameDesk — نظام إدارة محل بلايستيشن (نسخة Supabase)

تم ربط التطبيق بقاعدة بيانات **Marseille Academy** على Supabase.

## ما تم تغييره
- استبدال Firebase بالكامل بـ **Supabase**.
- استخدام نفس مشروع Supabase الخاص بأكاديمية مارسيليا.
- جداول منفصلة ببادئة `gamedesk_` حتى لا تتعارض مع جداول الأكاديمية.

## خطوات التشغيل (مهمة جداً)

### 1) إنشاء الجداول في Supabase
1. ادخل على مشروع Marseille Academy في https://supabase.com
2. من القائمة: **SQL Editor** → **New query**
3. انسخ **كل** محتوى ملف `gamedesk-supabase-setup.sql` والصقه
4. اضغط **Run**
5. لازم يظهر Success

### 2) فتح الموقع
- ارفع المجلد كامل على أي استضافة HTTPS (GitHub Pages أو Netlify أو Firebase Hosting أو أي سيرفر).
- أو افتحه محلياً عبر سيرفر بسيط (لأن المتصفحات تمنع بعض الميزات على `file://`).

```bash
# مثال سريع
npx serve .
```

### 3) لا تحتاج إعدادات إضافية
ملف `supabase-config.js` يحتوي بالفعل على:
- Project URL الخاص بمارسيليا
- الـ anon key

## المميزات
- 4 أجهزة مع حالة متاحة/مشغولة، عد تنازلي مباشر، تمديد وإنهاء.
- جلسات بالساعات أو نصف الساعة أو بالدقائق، وسعر قابل للتعديل.
- تسجيل المدفوع عند بدء الجلسة وتسجيل كل تحصيل لاحق كإيراد مستقل.
- مصروفات بتاريخ وتصنيف وتفاصيل.
- تقارير حسب الفترة، صافي التحصيلات ناقص المصروفات.
- تنبيهات صوتية وإشعارات متصفح عند انتهاء الجلسة.
- تصدير نسخة JSON احتياطية.
- تحديث فوري (Realtime) عبر Supabase.

## الجداول المستخدمة
| الجدول | الوصف |
|--------|--------|
| gamedesk_settings | إعدادات الأسعار واسم المحل |
| gamedesk_sessions | الجلسات النشطة والمنتهية |
| gamedesk_expenses | المصروفات |
| gamedesk_receipts | التحصيلات (الإيرادات) |

## ملاحظات أمنية
قواعد RLS الحالية مفتوحة (مثل مشروع الأكاديمية) لتسهيل الاستخدام بدون تسجيل دخول.
لا تنشر الرابط للعامة ببيانات حقيقية حساسة بدون إضافة حماية (مثل App Check أو تقييد IP أو إضافة Auth).

## طريقة الاستخدام
1. افتح الموقع.
2. من الإعدادات اضبط سعر الساعة ونصف الساعة والدقيقة.
3. من الرئيسية اضغط بدء جلسة على الجهاز المتاح.
4. استخدم تمديد / تحصيل / إنهاء حسب الحالة.
5. أضف المصروفات من قسم المصروفات.
6. راجع التقارير وصَدّر نسخة احتياطية بانتظام.
